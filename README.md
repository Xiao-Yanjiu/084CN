# 084CN

Windows x64《边狱巴士》中文配音制作与外置播放工具，原生 WPF 主程序。

## 下载与运行

在 Releases 下载 084CN-Windows-x64-portable-2026.11.15.zip，完整解压后运行 084CN.exe。建议放在可写目录，不要只提取 EXE。

首次进入“配置”，分别下载服务运行环境、IndexTTS2、但丁和旁白音色；显示安装占用、下载进度，支持不同组件同时操作。引擎自带独立运行环境，用户无需安装 Python。大型模型从官方 Hugging Face/PyTorch 等来源下载，需要网络和足够磁盘空间；安装过程中缓存与解压会额外占用空间。合成建议使用兼容 CUDA 的 NVIDIA 显卡，并保留足够内存及系统提交额度。

添加游戏路径，确保已安装零协中文且游戏资源已完整下载。软件启动时扫描一次，也可手动扫描。先勾选台词生成，再连接游戏；未生成的句子使用原声。游戏目录不需安装本程序插件，运行时连接游戏。

## 文件结构

- App：C# 与后端源码、工具、Config 配置、EngineAdapter 适配。
- ChineseAudio：生成中文音频。
- Engines：自动下载的运行环境、模型及参考音色。

普通角色参考当前原声，按零协中文生成；但丁使用“沉静青年男声-v1”，旁白使用“磁性沧桑中年男声-v1”。两个音色是 WAV 参考音频，不是独立训练权重。

## 构建

在 Windows PowerShell 执行 `./App/Build.ps1`，使用 .NET Framework 4.x C# 编译器构建根目录 EXE。主程序无需 Python；扫描、生成和播放服务使用自动下载的独立 Python 运行环境。引擎适配源码位于 App/EngineAdapter。

仓库包含应用及适配源码；UnityPy、Frida、vgmstream、FFmpeg 等运行二进制随免安装包分发。源码 ZIP 也包含这些配套工具，可构建运行版本。
